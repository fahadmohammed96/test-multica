# Scheletro generico

Per i progetti il cui stack NON ha ancora un template in questa repo.
Uso: (1) scegli lo stack ([DECISIONE] di kickoff, eventualmente
consultando il CoS); (2) fai lo scaffolding a mano con gli strumenti di
quello stack; (3) copia questo AGENTS.md + CLAUDE.md nella radice;
(4) issue di kickoff: il CoS verifica i [FATTO] eseguendo i comandi e ti
intervista sulle [DECISIONE].
Se quello stack tornerà, promuovi il risultato a nuovo template in
`templates/` — è così che la libreria cresce.
